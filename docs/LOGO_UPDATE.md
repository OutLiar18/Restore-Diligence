# Restore Diligence Logo Update

The website now uses the selected horizontal Restore Diligence logo throughout the header and footer.

## Identity used

- A capital **R** on the left.
- A traditional **Latin cross** in the centre, with the vertical stem longer than the crossbar.
- A capital **D** integrated on the right.
- `Restore` and `Diligence` are stacked in the approved red-and-gold script treatment.

## Website assets

- `public/brand/restore-diligence-logo.webp` — full responsive logo.
- `public/brand/restore-diligence-logo-600.webp` — smaller header version.
- `public/brand/restore-diligence-logo.png` — PNG fallback and structured-data image.
- `public/brand/restore-diligence-mark.webp` — compact R-cross-D mark.
- `public/favicon.ico` — browser-tab icon.
- `public/favicon-16x16.png` and `public/favicon-32x32.png` — small browser icons.
- `public/apple-touch-icon.png` — Apple/mobile shortcut icon.
- `public/site.webmanifest` — website app metadata.

The React `BrandMark` component automatically selects the correct optimized image size and format.
