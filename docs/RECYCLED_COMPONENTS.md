# Recycled JACP Foundation

The samoosa website retains and adapts these engineering patterns from the supplied
JACP source:

- React/Vite project structure.
- React Router routes with lazy-loaded secondary pages.
- Accessible skip link and route-loading state.
- Sticky responsive header.
- Mobile navigation with Escape-key support, focus management and backdrop.
- Reusable brand, primary CTA and WhatsApp components.
- Fixed mobile action bar.
- Reusable page metadata component.
- Structured-data component, changed from commercial services to FoodEstablishment.
- Responsive CSS variables, content widths, spacing and focus states.
- Reusable FAQ section.
- Responsive footer and direct contact details.
- Netlify single-page-app deployment workflow.

The visual identity, page structure, menu data, order experience and Christmas-drive
experience were rebuilt specifically for Restore Diligence rather than copied as a
simple recolour.
